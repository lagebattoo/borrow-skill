# 借物 · Borrow v0.1.1

Clearer implementation handoffs, reproducible local evaluations, and a refreshed
repository introduction. This remains an early pre-release under the MIT license.

## What changed

- **Portable handoff:** policy and plan templates name the sources the next agent
  must read. A worked CSV example shows how to continue without search-first.
  New evidence can replace a preference, but cannot silently relax user policy.
- **Repeatable evaluation:** fix Windows temporary-directory access and CLI working
  directories; preserve Skill bytes, reject escaping fixtures, record failed tool
  commands and retain timeout evidence. Optional companion Skills are copied only
  into temporary test projects. The Windows ACL regression check also works with
  Python UTF-8 mode and localized command output.
- **Decision boundaries:** add missing-requirement, explicit long-term budget
  change, fixed-policy conflict and fresh-session handoff cases, with reviewed
  responses, output artifacts and source hashes.
- **Repository presentation:** add a vector banner, concise overview, example
  decisions, installation shortcuts and separate evidence sets in the README.

## Validation

The refinement passed four synthetic scenarios across five independent Codex CLI
calls, plus four runner regression checks. The standalone implementation handoff
passed its two existing Node tests. Skill format, local references, JSON inputs
and preservation of the original design specification were checked. Released
`borrow/` files match the refinement's recorded hashes. Publication adds repository
documentation, presentation assets and the localized-output test-helper fix after
that behavior evaluation; the runner checks passed again with Python UTF-8 mode
both enabled and disabled.

The archived ECC search-first sample covers three scenarios and four earlier
calls at a pinned revision. Explicit handoff worked in that sample; implicit
search-first activation was not observed in the small implementation case.
Neither that historical sample nor the original eight-case baseline was rerun
against this release. Evidence is separated by source revision rather than summed
into a single reliability score.

Reports: [refinement](../tests/evals/REFINEMENT.md),
[compatibility](../tests/evals/COMPATIBILITY.md),
[reproduction](../tests/evals/README.md).

## Install or update

```text
Use $skill-installer to install the skill from
https://github.com/lagebattoo/borrow-skill/tree/v0.1.1/borrow
```

Only `borrow/` is installable. If you already have it, review and back up your
existing copy before replacing it; retain all references, templates, metadata
and the license. The repository is not an automatic update mechanism.
