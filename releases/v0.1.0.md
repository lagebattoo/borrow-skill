# 借物 · Borrow v0.1.0

Initial early release of a design-stage reuse planning skill for AI coding agents.

## Included

- A concise Skill entry point with scoped explicit and implicit activation.
- Reuse budgets, capability decisions, source routing, and implementation handoff.
- Optional templates for durable AGENTS.md policy and project reuse plans.
- Reproducible offline evaluation cases and reviewed evidence.
- Installation/usage documentation and the MIT license.

## Validation

Eight synthetic offline scenarios passed across nine independent Codex CLI calls.
The additional call verified that applying policy again did not duplicate rules
or modify an already adequate plan. The original tested Skill instructions are
unchanged; this release adds user-facing documentation and license packaging.

Test environment: Codex CLI 0.155.0-alpha.9.2, gpt-6-astra with high reasoning
effort. See the repository's `tests/evals/REPORT.md` for methodology and limits.

## Known limits

Real project usage, live external registry/source selection, real dependency
integration, other models/agent hosts, and all-plugin desktop activation have not
been validated. The sample results do not guarantee all future behavior. This
release is marked as a pre-release to make its early status explicit.

## Install

In Codex, ask:

```text
Use $skill-installer to install the skill from
https://github.com/lagebattoo/borrow-skill/tree/v0.1.0/borrow
```

Only the `borrow/` directory is the installable Skill. See the repository README
for manual project-local installation and invocation examples.
