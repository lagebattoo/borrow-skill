## 基础设施异常的处理

最初的 01 试运行使用隔离配置时未继承本机 Windows sandbox 设置，读取命令被策略阻止。该结果不计入通过数，也不作为 Skill 失败。测试执行器随后继承本机现有的 elevated sandbox 设置，保持 read-only/workspace-write 限制，没有使用 bypass；重跑后实际读取 CSS 成功。

07 的一个组合命令整体返回 1，原因是末尾 `rg` 未找到 AGENTS.md；同次工具输出已包含成功读取的 Borrow 正文。没有把该搜索的无匹配误记为 Skill 读取失败，也没有隐藏它。全部 9 次有效调用均有 `turn.completed` 且进程退出码为 0。
